## 3. How it works (three steps from the core flow)

1. **Open a service** — Services overlay → pick EC2, S3, IAM, Lambda, RDS,
   DynamoDB, VPC or any of ~150 services.
2. **Create a resource** — Launch instances wizard, Create bucket, Create
   user, Create function, Create database, Create table, Create VPC — same
   pattern everywhere.
3. **View and manage** — Resource detail page with tabs (Details, Tags,
   Monitoring), actions (start, stop, reboot, delete), cross-service links.

## 6. FAQ

- **Can I import from other console tools?** — Not yet; importer is on the
  roadmap if users ask for it.
- **Is my data private?** — Yes. The emulator runs against your local
  LocalStack/MinStack instance. Nothing leaves your machine.
- **Which services do you support?** — ~150 services, same navigation
  structure as the AWS Management Console. See the full list in the console.
