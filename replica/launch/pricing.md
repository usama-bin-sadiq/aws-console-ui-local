# Pricing — AWS Console Emulator Clone

## The original's public pricing

The AWS Management Console is free to use; you pay for the AWS resources you
provision. There is no console subscription fee.

For this emulator: **free**. It runs against your own LocalStack/MinStack
instance. There are no seats, no per-month charges, no paywalls.

## What reviewers said about price and billing

No reviews collected yet (see replica/feedback.md). When reviews are

## The model

- **Free plan:** One emulator instance, all ~150 services, no time limit.
- **No paid tiers planned** — this is a local emulator console, not a SaaS.
- **No surprise per-seat jumps** — there are no seats.
- **One-click cancel** — there is nothing to cancel; stop using it or delete
  the local data.

## Stripe products and prices

None — no Stripe integration. The user creates nothing; they just run the
console against their local emulator.
